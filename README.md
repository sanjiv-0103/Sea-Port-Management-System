# 🚢 Sea-Port Management System

A full-stack **DBMS mini project** developed using **Python Flask and MySQL** for efficient management of seaport operations including shipment booking, voyage scheduling, cargo tracking, customer management, payment processing, and **Excel report generation**.

---

## 📌 Project Description

The **Sea-Port Management System** is a database-driven web application designed to streamline and automate seaport logistics and reservation management.

It provides a centralized system for handling:

- Shipments
- Voyages
- Customers
- Cargo & Containers
- Payments
- Route Management
- Activity Monitoring
- Data Export & Reporting

The system minimizes manual errors, improves operational efficiency, and ensures structured database management.
